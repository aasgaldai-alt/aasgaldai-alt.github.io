# Салбарын мэдээ — долоо хоног бүрийн шинэчлэл (Даваа гараг)

`news/news.json` нь сайтын «Мэдээ» хуудас (medee.html) болон нүүр хуудасны мэдээний блокийн цорын ганц эх сурвалж.

```json
{
  "updated": "2026-10-22T09:00:00+08:00",
  "days": [
    { "date": "2026-10-22",
      "items": [
        { "id": "2026-10-22-01", "title": "Монгол гарчиг", "summary": "3–5 өгүүлбэр, өөрийн үгээр монголоор",
          "source": "World Highways", "url": "https://...", "tag": "Технологи", "region": "Европ" }
      ] }
  ]
}
```

- Шинэ өдрийг `days`-ийн **эхэнд** нэмнэ (шинэ нь дээрээ).
- `tag`: Технологи · Материал · Төсөл · ХАБЭА · Тогтвортой байдал · Бодлого · Техник
- Сүүлийн 30 өдрийг `news.json`-д үлдээж, хуучныг `news/archive-YYYY-MM.json` руу зөөнө.
- Өмнө нь орсон `url`-ыг давтахгүй.
- Зохиогчийн эрх: нийтлэлийг бүтнээр нь орчуулахгүй, эх сурвалжийн зураг хуулахгүй. Зөвхөн өөрийн үгээр тойм + эх линк.
- Санхүү, ажилтны нэр зэрэг компанийн дотоод мэдээллийг сайтад бүү оруул.
